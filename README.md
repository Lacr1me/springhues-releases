# springhues-releases

Springhues 的**软件工具**发布仓库（Windows / Android 等）。网站：https://springhues.com/

- 本仓库不提交源码和安装包，只用 **GitHub Releases** 分发。
- 一个 Release = 一个软件的一个版本，tag 形如 `simple-download-windows-v0.2.0`。
- 附件文件名只用 ASCII：`<App>-<版本>-<平台>.<扩展名>`，并附同名 `.sha256` 校验文件。
- 现有软件：简单下载（Windows、Android）。
- 站点源码在 Lacr1me/game-daily，维护与发布流程见该仓库的 `docs/HANDOFF.md`。
